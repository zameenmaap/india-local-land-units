# Local land-unit conventions of India, with primary-source citations

This table records local land-unit definitions compiled by Zameen Maap, with conversion factors, geographic limits, historical context and primary-source citations. It has one row per convention and unit: 77 rows across 21 states, covering 54 conventions. Guide links are present only for rows that have their own guide page. National and standard-unit choices are excluded.

Values were verified against primary sources on the page image of the cited definition, with title or imprint details checked where documented. The Maharashtra, Punjab and West Bengal schedule sources were checked as official indexed text rather than page images. The table carries those verification results; preparing this table did not involve new source verification.

## Column dictionary

| Column | Meaning |
| --- | --- |
| convention_id | Stable identifier for the convention. |
| unit_id | Stored unit identifier within the convention; together with convention_id, uniquely identifies the row. |
| country | Country code, IN (India). |
| state | State name. |
| district_or_scope | Districts, localities and geographic limits, separated by semicolons. Historical names and partial-district limits are retained. |
| unit | Name of the selected local unit. |
| value_as_printed | Amount from the unit's own basis definition, expressed for one unit, including ratios to another local unit. Stored amounts retain their digits, in plain decimals with trailing zeros removed. Empty for square-length definitions or claims without a stored one-unit amount or local-unit ratio. Definitions are paraphrased. |
| value_unit_as_printed | Unit corresponding to that amount. Empty when the amount is unavailable. Spelling follows the table's unit labels. |
| square_feet | Area of one selected unit in square feet. The number of decimals is capped at six, rounded to nearest with ties to even; trailing zeros are removed and scientific notation is not used. |
| square_metres | Area of one selected unit in square metres, with the same six-decimal cap and formatting as square_feet. |
| source_title | Title of the primary source supporting the definition. |
| source_year | Publication year or year range; empty if unknown. |
| source_volume | Explicit volume and, where supplied, part from the source title; empty if absent. |
| source_page_locator | Location of the definition, including printed or PDF page, table or section details. |
| source_scan_url | Link to the source, usually a document scan; some links lead to official web pages. |
| scope_notes | Historical scope and cautions about the convention. |
| guide_url_en | English guide for the convention and selected unit, where available. |
| guide_url_hi | Corresponding Hindi guide, where available. |

## Limits

Historical definitions do not establish present-day use. Match the scale on your own land record, including its locality, settlement system and date. A state or district name alone does not determine the applicable convention. Some definitions are approximate, including Didwana, Mana and the Manipur census equivalents; decimal factors do not imply survey precision. Verification supports the definition within its stated convention; it does not certify a parcel or establish legal measurement authority. Blank cells mean unavailable or inapplicable information. Source citations support the selected definition and may not include every corroborating source.
